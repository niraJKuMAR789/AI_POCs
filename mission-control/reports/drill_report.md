### Investigations

**F1 → incident #2.** Latency regression (latency): most consistent with tool failure (tool_name=rerank).

- `trace` a9d249c3904903998c28991e6d9b88f0: representative outlier trace
- `trace` 9f114cf4d6f629ffbd54d86fed008695: representative outlier trace
- `component` tool:rerank: p50 latency 252.36x baseline
- `change` 2: atlas-retrieval 1.4.0: reranker moved to shared GPU pool (6 min before the incident window)
- `anomaly` 4: trace_duration_p95_ms: 479.7 vs 24.76
- `anomaly` 5: trace_duration_p95_ms: 374 vs 24.76

Recommended: Check the failing tool's upstream dependency; Add retries with backoff or a circuit breaker.

**F2 → incident #3.** Cost per trace spike (cost): most consistent with prompt regression (prompt_version=sql-v2).

- `trace` 0a88a2dcc12c3af02f1d9bef8f618b36: representative outlier trace
- `trace` ac1f36dc49bbbf919665005b7bf8de60: representative outlier trace
- `attribute` prompt_version=sql-v2: 100% of outlier traces vs 3% at baseline
- `change` 4: SQL prompt sql-v2 rolled out to 100% (1 min before the incident window)
- `anomaly` 7: cost_per_trace_usd: 0.00187 vs 0.001155
- `anomaly` 8: cost_per_trace_usd: 0.001796 vs 0.001155

Recommended: Roll back the prompt change; Add a token-budget check to prompt CI.

**F3 → incident #1.** Error rate spike (error_rate): most consistent with provider degradation (model=offline-keyword-baseline).

- `trace` 9b2bc78ccb4407981e7817bb911bf6bb: representative outlier trace
- `trace` 19b930f70b8beadb549949e416825027: representative outlier trace
- `component` llm:offline-keyword-baseline: error rate 80% vs 0% at baseline
- `anomaly` 1: trace_error_rate: 0.2667 vs 0.002
- `anomaly` 2: trace_error_rate: 0.25 vs 0.007
- `anomaly` 3: trace_error_rate: 0.2727 vs 0.007

Recommended: Fail over to a secondary model/endpoint for the affected model; Check the provider status page and NIM endpoint health.
